# Publier les conditions de Zero Unit

Page statique en anglais, français et arabe. L'arabe utilise `dir="rtl"`. Tout le contenu est consultable sans JavaScript, compte, cookie, police distante ou outil d'analytics.

## Publication sur GitHub Pages

1. Créer un dépôt public nommé `zero-unit-terms`.
2. Mettre **le contenu de ce dossier à la racine du dépôt** : `index.html`, `.nojekyll` et ce README. Ne pas envoyer le projet Unity, sa clé de signature ou ses identifiants.
3. Dans le dépôt : **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Choisir **main**, puis **/(root)**, et enregistrer.
5. Attendre la publication et ouvrir l'URL affichée par GitHub Pages. Activer **Enforce HTTPS** si l'option est proposée.
6. Tester le lien dans une fenêtre privée, sur téléphone, sans connexion à GitHub. Vérifier les trois langues et les caractères arabes.
7. Coller **l'URL du site publié** dans le champ Terms of Service de Google Play. Ne pas utiliser l'URL github.com du code, le ZIP, un PDF ou l'éditeur GitHub.

Avec ce nom de dépôt, l'URL habituelle sera :

`https://VOTRE-PSEUDO.github.io/zero-unit-terms/`

Cette adresse est un exemple : remplacer VOTRE-PSEUDO, puis utiliser l'adresse réellement affichée dans Pages. Aucune URL publique n'a encore été créée par la préparation de ces fichiers.

Une seule URL présente les trois langues. Des liens directs sont aussi possibles : `/#en`, `/#fr`, `/#ar`.

Si vous gardez le dossier `terms` dans un autre dépôt Pages déjà publié, son URL sera celle de ce site suivie de `/terms/`. GitHub Pages ne propose pas le dossier arbitraire `/terms` comme source de branche : utiliser la racine ou `/docs`.

Documentation : https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Le texte a été adapté aux fonctionnalités connues du jeu : trois modes, progression locale, monnaie virtuelle et publicités, avec préservation des droits légaux impératifs. Vérifier que **Nexus Labe** est bien l'identité sous laquelle vous fournissez l'application et que `nexus.labe@gmail.com` reste joignable. Les deux noms connus de l'application et le package `com.zerounit.lastdefense` sont indiqués pour l'identifier clairement.

Conserver une politique de confidentialité distincte, accessible depuis la fiche Google Play, et maintenir les conditions à jour si la sauvegarde, les achats ou les services changent. Ce texte ne constitue pas une validation juridique personnalisée ni une garantie d'acceptation par Google Play.
